# Óticas Caetano

O site está em `dist/` e usa HTML, CSS e JavaScript sem etapa de compilação. Abra `dist/index.html` ou sirva a pasta com `python -m http.server 4173 --directory dist` a partir deste diretório.

O lookbook mede 440 alturas de tela no modo animado. A rolagem vertical move a faixa horizontal enquanto o palco fica fixo. Com a preferência de movimento reduzido ou uma janela muito baixa, os quatro quadros aparecem em sequência vertical.
